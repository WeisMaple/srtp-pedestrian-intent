SRTP 论文复现报告
日期：2026-10-27

本轮已完成 346 段 JAAD 视频的检测、跟踪、姿态提取、训练集重建、模型从头训练和视频演示。ST-GCN 最终内部验证准确率为 96.38%，最佳轮次为 96.69%，接近论文约 97.5% 的描述。LSTM 使用原代码的权重衰减时出现预测退化；保持相同种子、划分及其余训练参数、将权重衰减设为 Adam 默认值 0 后，验证损失恢复到接近论文曲线的量级。串联预测的效果仍弱，尚未完整复现论文的全部结果。

2. 数据与实现
原始视频：F:\Artificial_Intelligence\srtp\data\JAAD_clips，共 346 段。
原始压缩包仍在 D:\下载\JAAD_clips.zip。F 盘空间有限，大型中间数据与结果均放在 D 盘。
标注来源：JAAD 官方仓库 https://github.com/ykotseruba/JAAD 的 JAAD_2.0 分支；来源记录见项目 data/annotation_source.json。
所有视频的尺寸与帧数已与 XML 核对。共处理 82,032 个视频帧，匹配到 374 条带行为标注的行人轨迹，保存 46,685 次有效姿态观测。
流程：YOLOv7x 检测 → 原始 DeepSORT/ReID 跟踪 → 原 DataProcess.match_bboxes 的 IoU 对齐规则 → YOLOv8n-pose 姿态 → 原 Dataset 的归一化及滑窗。
保留原匹配代码“前 11 个框、按列表索引”等行为，没有借此更换匹配规则以提高分数。姿态裁剪使用原始画面；预处理省略可视化覆盖层，并使用 GPU 批处理提速。单帧与批量检测对比的框坐标差为 0，分数最大差约 0.000244。
分类输入：50 帧、17 关键点、x/y/置信度，滑窗步长 10；共 3,173 个样本。LSTM 输入 50 帧预测后续 10 帧；共 2,880 个样本。短轨迹按原数据集逻辑丢弃。
分类标签完全沿用 train.py 的 mode=2：JAAD crossing=-1/0/1 映射成类 0/1/2；三个类的窗口数分别为 460/222/2491。
适配器与原 DataSet.py 在三类和短序列案例上比较，输入及标签一致，最大数值差为 0。

3. 训练环境与设置
环境：F:\Anaconda\envs\d2l；Python 3.9.23，PyTorch 2.2.2+cu121，RTX 4060 Laptop 8 GiB。
训练使用 CUDA、FP32，种子 2026；窗口级随机划分 80%/20%，batch_size=128。
ST-GCN：原模型结构，SGD，lr=0.001，momentum=0，weight_decay=0；训练 125 轮，保留第 100 轮。
LSTM：原 10 层结构，input_size=51、hidden_size=256、一次输出 10 帧；Adam，lr=0.001，训练 100 轮。原代码组 weight_decay=1e-4；对照组 weight_decay=0。两组从头训练，种子与样本索引相同。
论文未写 LSTM 的 weight_decay，0 是本轮声明的 Adam 默认参数对照，无法据此确定论文作者实际使用的数值。
训练耗时：ST-GCN 约 8.68 分钟；两组 LSTM 各约 72 秒；视频预处理约 48.9 分钟。
运行时使用 python -s 隔离用户目录的库，并设置 MKL_THREADING_LAYER=SEQUENTIAL，避免 OpenMP 库冲突。

5. LSTM 预测结果与退化诊断
同一组 576 个验证窗口：
                              验证 batch 均值之和   按样本加权平均 MSE
原始提供权重                  1.3344                 0.26631
原代码衰减 1e-4，从头训练     4.5251                 0.90736
衰减 0 对照，从头训练        1.3865                 0.27974
衰减 0 对照最后一轮训练损失之和为 2.0898，接近论文“训练约 2、验证约 1.6”的曲线量级。batch 均值之和随样本数和批次数变化；原论文未提供可精确核对的样本划分，因此该量级接近不能等同于同一基准上的数值复现。
原代码衰减组对 16 个不同输入给出的输出离散度为 0，第一层输入权重的 float64 范数约 1.49e-38，已接近消失；其 float32 范数计算下溢为 0，权重并非每个元素都严格为零。保持其余条件相同，仅移除衰减后训练恢复。
简单基线：未来 10 帧均复制最后一帧姿态，其 MSE=0.26423，仍优于衰减 0 LSTM 的 0.27974（LSTM 高约 5.87%）。此处参照目标为自动提取的未来姿态，包含检测噪声。

6. 串联预测与归一化实验
按论文及原代码的推理归一化方式，把固定前 50 帧和待分类序列当成两个“人”共同归一化；这是论文明确描述的设计。使用本轮最终 ST-GCN 与衰减 0 LSTM，在 635 个验证历史窗口上重建串联预测：
同一行人参考序列：74.33%；同一视频已匹配行人参考序列：74.96%。后者低于多数类基线 77.32%。
视频参考选取最早匹配行人的首 50 次姿态，原始流程可能先遇到未匹配行人，因此这里是对已检测历史的串联诊断，范围不同于在独立视频上逐帧评测完整管线。
补充实验改成两网络均使用保存的训练归一化参数：串联准确率 79.06%，复制最后一帧后分类的基线为 77.95%。这是本轮探索改动，另列于 training_stats_alignment_ablation.json，不能计入论文原方法的复现分数。结果支持进一步检查训练/推理归一化差异。
90 帧新权重视频演示已成功输出，逐帧读回 90 帧，产生 55 次意图标注。预测调用约 15.74 秒，包含内部模型准备过程，不包含模块导入；原预测函数中姿态、LSTM 与分类器的 CPU 分配保持原样，检测用 CUDA。该演示用于验证功能和文件完整性。

7. 分数的适用范围
本轮沿用原代码的窗口级随机划分及先归一化后划分：分类验证窗口中 625/635（98.43%）与训练窗口共享行人及重叠历史；LSTM 为 568/576（98.61%）。归一化统计也使用了验证样本。这些分数表示原代码式内部验证表现，不能作为独立新视频的泛化精度。
论文原始训练样本选择、随机种子与逐样本划分未提供；本轮使用全部 346 个本地视频、现有标注及明确记录的种子重建。GPU 批处理、取消画面覆盖层也可能引入特征差异。
下一步最有价值的实验是按 JAAD 官方视频划分重建训练/验证/测试集，只用训练集拟合归一化，并固定“预测多长时间后的意图”及其标签定义后测试完整管线。这需要独立的一轮训练和评估，当前产物已为该实验保留全部样本来源索引。

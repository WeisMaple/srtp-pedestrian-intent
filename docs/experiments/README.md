# 实验结果索引

本目录保存报告、指标、训练曲线、划分及逐样本分类结果；不包含数据集、视频或模型权重。JSON 中的 D/F 盘路径为实验执行机器的产物来源，阅读报告请使用下面的仓库内链接。

| 实验 | 主要结果 | 口径 |
|---|---|---|
| [旧前端复现](reproduction_20261027/复现报告.txt) | ST-GCN 最终96.38%，最佳96.69% | 随机窗口内部验证，有历史重叠及归一化泄漏 |
| [独立视频对比](independent_20261028/对比报告.md) | 共同598点：旧版74.75%，新版76.92%；Macro-F1为0.305→0.292 | 官方188/32/126视频划分，两组从头训练 |
| [新版内部验证](modern_internal_20261028/结果说明.md) | ST-GCN 最终97.00%，最佳98.00%（第121轮） | 沿用原窗口划分规则，200个验证窗口，97.5%历史重叠 |

内部验证模型使用全部视频构建训练窗口，不能重新用于宣称上述独立测试集上的泛化成绩。两个内部实验的有效样本不同，也不构成逐样本的新旧精度比较。

独立视频对比的准确率差值为2.17个百分点，按视频配对bootstrap 95%区间为−1.55至+6.15个百分点；多数类基线为77.59%。目前没有证实意图区分能力改善。

三段同源视频的整体吞吐为4.16→22.05 FPS，但行为预测次数为261→108，因此5.30倍是这次实际流水线的吞吐比，不是相同工作量的纯算法加速。相同骨架、batch=1的行为推理中CPU快于CUDA，详见报告。

代码与运行顺序见 [实验说明](../../independent_20261028/README.md)。`files_manifest.json` 记录复制时的文件大小及SHA256；Git可能按仓库属性规范化文本换行，核验源文件时应注意这一点。

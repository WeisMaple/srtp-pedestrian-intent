# 本地视频分析工作台设计

状态：用户于 2026-10-29 确认，进入实现。

项目定位修正：用户明确本项目是**深度学习课程大作业**。实际界面、标题、页脚和说明统一采用课程大作业表述；早期概念图中的 SRTP 标识已作废，布局与交互设计继续采用已确认方案。

## 目标与已确认选择

用户要求一个可操作的本地网页，支持选择视频、开始分析、显示骨架与行人 ID、显示预测类别、保存结果，并用精美动画展示整个计算过程，以支撑课堂材料中的“系统设计”和“界面展示”。用户已选择 **React＋Python 精致工作台**。

交付两个连贯页面：**视频分析**与**运算过程**。两页使用同一实际分析任务、行人 ID 和预测数据。界面采用中文，运行于本机；首版不包含移动端、账号、云部署、摄像头接入或重新训练模型。

## 方案选择

- **React＋Vite / Python FastAPI（用户已选）**：能控制视频布局、SVG 骨架、任务反馈与计算回放动画；需要前后端构建和本地启动入口。
- **Streamlit**：可较快搭建上传、推理和下载流程，复杂动画和布局的定制空间较小。

## 视觉设计与状态

完整界面概念由 Image Gen 生成，作为待确认的视觉方向：浅冷灰底、白色操作区、墨色文字、克制的翠绿强调色；运算舞台为深蓝黑底。视频是工作台的主要视觉焦点，避免把界面做成指标卡片墙。

概念文件：`docs/design/web-workbench-concept.png`、`docs/design/web-process-concept.png`。图中的视频、分数、人数、时长、帧数和日志为布局示意；实现时全部来自实际任务。只有分析结果模式叠加骨架、ID 和类别；原始视频模式不叠加。界面状态以本节及后文为准。

### 视频分析

- 顶部品牌文字“深度学习大作业 · 骨架时序分析”，导航“视频分析 / 运算过程”，模型状态根据本地文件检查显示。
- 左侧输入栏：拖放或选择本地视频、文件名及实际元数据、主按钮“开始分析”、运行期间的“停止分析”、完成后的“保存结果”。支持 MP4 / MOV / AVI 的解码尝试；无法读取时明确报错。
- 中央视频舞台：“原始视频 / 分析结果”切换、当前帧/总帧与进度。分析过程中显示实际已处理帧的标注预览；完成后支持播放保存的结果视频。
- 右侧行人列表：ID、运行状态或预测类别、三个类别分数；选中 ID 后运算过程页跟随该行人。无人、历史不足、姿态不足均有明确状态，不填造分类。
- 下方六阶段流程带：视频解码 → YOLO26 姿态检测 → ByteTrack 身份跟踪 → 50 次骨架观测 → LSTM 未来骨架 → ST-GCN 意图分类。可进入运算过程页。

空态不展示伪造的行人结果。上传后等待开始；运行时防止重复开始；完成后启用下载；失败可选择其他视频重试。刷新页面可恢复当前任务状态。保存菜单提供标注视频 MP4、分析数据 JSONL、完整结果 ZIP。

### 运算过程

- 同一套顶部导航、行人选择器及返回工作台入口。
- 左侧六阶段导航；中央深色舞台呈现历史骨架序列、LSTM 的五组 10 帧预测、未来骨架、COCO17 图结构与三类分数。
- 观测与预测使用不同颜色和线型；画面中的实测骨架、未来预测骨架有清楚图例。
- 实时模式展示实际任务阶段；“回放流程”支持播放/暂停、0.5× / 1× / 2×、步骤跳转。
- 回放按步骤解释记录的运算结果，播放速度不代表真实推理耗时。ST-GCN 图传播动画是结构示意，不伪装为隐藏层激活可视化。
- 没有可用真实轨迹时展示空态或明确标注的结构示意，不能把合成示例当成已处理结果。

## 动效设计

界面反馈主要使用 160–240 ms 的 opacity / transform 过渡；结果条和类别变化采用短过渡。流程讲解使用数据粒子沿路径移动、历史帧依次入列、骨架关节点点亮、五轮未来骨架依次展开、分类分数条出现。回放步骤可停留约 0.8–1.2 秒，支持用户调速与暂停。

任务阶段由真实事件驱动。不要让未执行的阶段提前标记完成；检测和跟踪来自同一次 `YOLOPoseTracker` 调用，允许共享前端完成事件，不编造独立耗时。浏览器隐藏时暂停装饰动画；遵循 `prefers-reduced-motion`。长任务期间主界面保持可操作。

## 模型与数据约束

默认使用已下载并校验的 `weights/final/model_config.json` 配套模型：YOLO26s-Pose、ST-GCN 第 121 轮、LSTM 第 68 轮、`legacy_pair`、不启用姿态平滑。保留原 50 观测 → LSTM 五轮 × 10 → ST-GCN 的流程，离线入口默认结果应保持一致。

三类 UI 文案为“其他 / 不过街 / 过街”，`其他` 对应 JAAD irrelevant；历史不足、缺失、已过期是额外运行状态。分数标注为模型分数，不把内部 98% 分类验证成绩当作视频预测精度。分析吞吐与视频原始帧率分别记录，不能用正常播放的视频证明实时性。

## 后端结构与任务接口

采用 FastAPI / Uvicorn，单任务工作线程，推理不阻塞 HTTP。React＋Vite 构建后的静态文件由 Python 服务提供；本地开发可用 Vite 代理。默认只监听 `127.0.0.1`，启动命令目标为 `python run_web_demo.py`。新增网页依赖单列，现有摄像头和离线代码保持可用。

前端目录拟为 `web_demo/`；后端拟为 `modern_pipeline/web/`。运行文件放在 Git 忽略的 `artifacts/web/jobs/<uuid>/`，不会覆盖用户输入。每个任务生成独立输出目录，任意同时只执行一个推理任务；新的执行请求在忙碌时返回明确状态。

接口约定：

| 接口 | 职责 |
| --- | --- |
| `GET /api/health` | 模型/编码器可用性与当前任务 |
| `POST /api/jobs` | 上传视频，创建 UUID 任务并返回实际解码元数据 |
| `POST /api/jobs/{id}/start` | 开始真实分析，重复请求不重复执行 |
| `GET /api/jobs/{id}` | 可恢复的完整任务状态 |
| `GET /api/jobs/{id}/events` | SSE 任务进度和阶段事件，断连后可重新获取快照 |
| `GET /api/jobs/{id}/preview` | 最近处理帧 JPEG，预览限流，不向前端逐帧传输全分辨率原片 |
| `POST /api/jobs/{id}/cancel` | 请求在可中断边界停止；取消状态不冒充完成 |
| `GET /api/jobs/{id}/trace` | 有界采样的真实流程回放数据 |
| `GET /api/jobs/{id}/files/{name}` | 原片/标注视频/JSONL/指标/ZIP，按任务白名单提供文件 |

任务状态为 `ready → loading → running → encoding → completed`；另有 `failed` 和 `cancelled`。上传默认最大 500 MB，可通过服务启动参数调整；超限、空文件、错误格式、无法解码均有可读错误。视频路径由服务生成，原文件名仅作为显示元数据。删除和多用户权限管理不属于首版。

运行状态写入任务元数据；服务重启后可读已完成任务，未完成任务标为中断。浏览器断开不自动杀死正在运行的分析。停止请求在当前模型调用结束后的帧边界生效；取消后保留状态和日志，但不提供伪装成完整结果的下载。

## 与现有推理代码的连接

在现有 `modern_pipeline.cli.run` 和 `BehaviorPredictor` 上增加默认关闭的观察/取消钩子，以复用实际计算及输出逻辑。无钩子调用维持原签名兼容和行为。观察事件覆盖前端、历史缓存、LSTM 各轮、分类和已渲染帧；后台只序列化限流后的必要数据。

每轮 LSTM 回放数据对应真实推理产生的 10 帧姿态，恢复到与视频一致的坐标后再发送；不使用额外轨迹规则改写神经网络输出。回放仅保留有界样本，建议最多 60 个时间快照、每个至多 3 个行人，不保存每帧所有隐藏张量。任务结果 JSONL 仍按原流程写出逐帧记录。

标注 MP4 必须可在浏览器播放。现有 OpenCV MP4V 写出后，用本地 ffmpeg 转为 H.264 / yuv420p / faststart，编码完成再开放最终视频下载；这台 Mac 已有 `/opt/homebrew/bin/ffmpeg`。其他机器启动时检查 ffmpeg，缺失则提示安装。首版结果视频沿用原流程的无音轨输出，不承诺保留输入音轨。原片可解码但浏览器不支持时，由后端生成兼容预览。

## 视觉系统与实现边界

待确认色板：页面 `#F5F7F9`、面板 `#FFFFFF`、主文字 `#15252B`、强调 `#117B65`、舞台 `#102129`。最终从已确认图片提取并锁定色板、字级、尺寸、间距、组件和图标清单，避免实现时任意改版。中文使用系统无衬线字体；页面本地运行不依赖字体 CDN。SVG 图标、骨架、路径及动画为原生代码，概念图不作为产品界面的截图背景。

桌面主屏以 1440px 级别布局为基准；窄屏重排为视频优先、控制栏和列表依次下移，不额外开发移动端产品。键盘可选文件、操作按钮及切换页面；状态变更提供可访问反馈。

## 验证与交付

- 推理钩子启闭的行为一致性、50 观测初始化、姿态缺失/断轨、真实未来骨架/分数传递。
- 上传/启动/停止/失败/重复请求、任务隔离、重新加载状态、视频与 ZIP 实际下载。
- 至少完成一段真实模型的视频推理检查，并解码读回输出；不将替身或合成视频检查说成现场准确率。
- 使用真实浏览器测试空态、上传、运行、运算过程播放、完成下载、窄屏和减少动画模式。Browser/IAB 不可用时记录原因后用 Playwright。
- 对照已确认设计图与浏览器截图做视觉检查，检查动画在推理负载下的响应性。
- 提供一条启动命令、依赖安装说明、模型路径、结果目录及必要限制；为论文截图保留可直接打开的完整页面。

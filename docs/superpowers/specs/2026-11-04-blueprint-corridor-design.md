## 2. 核心概念

**跟着一个真实行人，从一帧画面走进模型。**

六步在同一个三维蓝图长廊中连续展开：

1. **视频帧**：一帧源画面进入模型。
2. **YOLO 骨架**：检测框与 17 关节被识别出来。
3. **ID 绑定**：骨架归属到一个 ByteTrack ID，并累积为 50 帧历史。
4. **LSTM 预测**：历史被编码，五轮预测未来 50 帧骨架。
5. **ST-GCN**：未来骨架在空间邻居与时间窗口上聚合。
6. **意图**：256 维特征变成三个类别分数。

两处计算放大镜：

- **② 骨架识别处的卷积放大镜**：3×3×RGB 窗口 → 27 项乘加 → BN → SiLU → 写回特征图；随后沿 23 模块特征传送带展开每个模块的代表性卷积。
- **⑤ 时空卷积处的图放大镜**：真实邻接边上的消息传递、完整 51 项空间求和；9 个时间位置 × 全部输入通道的时间卷积。

真实性原则（贯穿全设计）：

- 所有显示数值来自实时前向钩子或记录重算；未采集显示「未采集」，不补零、不编造。
- ByteTrack 匹配代价矩阵没有记录，界面不展示虚构的关联分数；ID 是分析时的真实归属。
- 每个模块/块只展示一个代表性输出通道与位置，界面明确标为「代表算式」。
- 讲解播放速度是教学时间，不是模型推理时间。
- 融合 BN 与未融合 BN 分别标注，不把融合权重伪装成可拆分的 BN。

## 4. 六步长廊

### 4.1 空间布局

- 一条缓弯的走廊，六个展位沿 Catmull-Rom 曲线排列；近侧是画面、骨架与 ID 带，远侧是模型结构，地面为细网格。
- 展位默认只显示当前步骤与前后各一步的轮廓，其余淡出；避免六个阶段同时抢注意力。
- 特征图是薄发光平面 + 线框边缘，不再是方块阵；只有当前检查的单元点亮。
- 骨架：关节为实例化点，骨骼为有世界宽度的线段；观测/预测/未来用线型与颜色区分。
- 意图柱为三根细长线框柱，不铺满画面。

### 4.2 镜头

- 透视相机，FOV 34°，无滚转，偏航/俯仰受控；自动讲解时沿样条移动，单次 1.2–1.8 秒。
- 每个步骤有全景机位与 2–4 个「动作机位」；讲到卷积时贴近局部，讲完回到全景。
- 用户拖动/缩放/点击即暂停自动；出现「回到主线」。
- 镜头自动聚焦当前对象时，保留标签空间，不把对象推到画面边缘。

### 4.3 分步内容

| 步 | 展位 | 画面 | 数据 |
| --- | --- | --- | --- |
| ① | 视频帧 | 源帧铺在灯箱平面；帧号、时间、分辨率；Letterbox/RGB/÷255 的画幅过渡 | 任务元数据、预览帧 |
| ② | YOLO 骨架 | 原图上所有检测框与 17 关节；选中行人高亮，其余退暗；关节置信度用点亮度表示；COCO17 拓扑放大镜 | 实时 `tracks`：`bbox`、`keypoints`、`detection_confidence`、`pose_accepted` |
| ③ | ID 绑定 | 检测骨架 → ID 标签的绑定动画；选中 ID 的历史骨架沿时间轴排成姿态带，最多 50 帧；有效观测 0–50、断轨与姿态缺失留缺口 | 实时 ID、`history_length`、逐帧关键点；不展示匹配代价 |
| ④ | LSTM 预测 | 50×51 输入带推入 10 层 LSTM 状态柱；五轮 × 10 帧未来骨架依次展开；首轮解码器完整内积可展开 | 实时 LSTM 层输出、五轮预测、未来骨架 |
| ⑤ | ST-GCN | 未来骨架图悬浮；空间邻居沿骨骼汇聚，时间卷积沿时间轴滑动；10 个块以三层薄平面叠放；残差与 ReLU 合并 | 实时块输出；代表空间/时间卷积 |
| ⑥ | 意图 | 256 维池化特征收束为三条 logits，Softmax 后成为三根分数柱；选中类别点亮 | 实时分类输出、Softmax、三项概率 |

### 4.4 预热与空态

- 有效观测不足 50：④⑤⑥ 显示「等待 50 次有效观测」与进度 `n/50`；已采集的骨架与 ID 正常显示。
- 无检测：当前帧显示「本帧未检测到行人」，不沿用上一帧伪造。
- 姿态缺失 / 断轨：在 ID 带留缺口并标注状态。
- 实时分析尚未收到某层：显示结构轮廓与「等待该层输出」，不填数值。
- 分析完成后再进入：默认使用最后的实时快照；可切换「记录讲解」重算。
- 自动讲解受真实数据门控：某一步所需数据尚未到达时，画面停在「等待该步输出」，不预演未发生的阶段；数据到达后继续。

## 5. 卷积细节

### 5.1 YOLO 首层放大镜

- 在源帧上选中一个 3×3 RGB 窗口，镜头贴近；显示 3 个通道 × 9 个位置 = 27 个输入、27 个权重、27 个乘积、部分和、偏置。
- 求和后按真实配置执行 BN（未融合时）或标注融合，再执行 SiLU，写回输出特征图的一个格点。
- 卷积核在特征图上滑动：每移动一个位置，输出格点亮起；可单步、暂停、倒拖。
- 界面明确：这是第一层的一个代表性输出通道/位置，不是整张特征图的全部标量。

### 5.2 YOLO 23 模块特征传送带

- 23 个模块沿一条曲线排列，显示编号、类型、输入来源、输出尺寸与通道数。
- 选中模块进入「模块放大镜」：
  - 输入特征图、卷积核、输出特征图三块薄平面。
  - 一个代表性输出通道/位置的完整乘加（输入通道 × 核高 × 核宽）。
  - 若该模块含多个卷积，界面标明所选代表卷积的模块路径；不是该模块内所有算子。
- 特征平面用真实采样点亮度表示，不生成虚构纹理。
- 模块可跳转；缺失详细算式的模块显示「等待详细采集」与覆盖进度。

### 5.3 ST-GCN 空间与时间卷积

- **空间**：选一个目标关节（默认度数最高的关节），显示三个分区 `A × edge_importance` 的有效系数、所有 51 项投影特征与乘积、部分和、独立采集输出与重建误差。
- **时间**：9 个时间位置 × 全部输入通道的完整乘加；默认展示中间时刻，另提供边界时刻用真实零填充说明越界规则；残差分支与 ReLU 合并显示。
- 10 个块可切换；每块显示通道数、时间长度与残差模式。
- 支持在真实拓扑上点选接收关节，前端重定向完整算式；不重新跑模型。

      {"index": 1, "in_channels": 64, "out_channels": 64, "temporal_kernel": [9, 1],

### 8.3 代表卷积的选取规则

对每个 YOLO 顶层模块，按子模块顺序优先选择第一个 `groups == 1` 且 `kernel_size != (1, 1)` 的 `nn.Conv2d`；若没有，选择第一个 `groups == 1` 的卷积；若仍没有，该模块不提供代表卷积，只显示输出特征。

- 代表输出固定为通道 0、空间中心位置 `(H//2, W//2)`；在同一模块内稳定可比。
- ST-GCN 每个块的代表输出为通道 0、中间时刻、度数最高的关节；空间邻域包含三个分区的全部 51 项。
- 记录 `module_path` 与选取规则，界面可显示「代表输出」说明。
- 单个代表卷积的项数上限为 4096（输入通道 × 核高 × 核宽）。若选中卷积超过上限，先在同一模块内改选项数更小的非 1×1 卷积；若仍超限，该模块只显示输出特征并标注「代表卷积项数超限」，不截断求和。记录模式可用按需端点查看该模块。

### 8.4 紧凑计算载荷

卷积是稠密网格，不再逐项发送索引。新增 `dense_conv` 计算模式：

```json
{
  "id": "yolo.conv.4",
  "stage": "yolo",
  "operation": "dense_conv",
  "module": 4,
  "target": {"channel": 0, "y": 160, "x": 160},
  "term_axes": ["in_channel", "kernel_y", "kernel_x"],
  "term_shape": [64, 3, 3],
  "inputs": [0.12, 0.44, -0.08],
  "weights": [0.03, -0.11, 0.07],
  "bias": 0.01,
  "actual": 0.37,
  "activation": "silu",
  "fused": true,
  "input_shape": [1, 64, 320, 320],
  "stride": [1, 1],
  "padding": [1, 1],
  "formula": "y = SiLU(Σc Σky Σkx(x × W) + b)"
}
```

示例只列出前 3 项；实际 `inputs` 与 `weights` 各包含 `64 × 3 × 3 = 576` 项。

- 前端把 `inputs`、`weights` 与 `term_shape` 展开为完整项，生成 `channel / kernel_y / kernel_x` 标签、乘积与 Kahan 部分和。
- `fused=false` 的记录重算使用 `activation: "batch_norm_silu"` 并附带 `bn` 参数；`fused=true` 的实时代表卷积只展示融合卷积 + SiLU，`fused` 字段驱动界面标注。
- 现有逐项 `inputs + input_indices` 模式保留，用于记录重算与 LSTM 门等非稠密计算。
- 所有数值按实时 5 位小数、记录 6 位小数舍入；非有限值显式记为 `null`。

### 8.5 实时详细采集

- **层输出**：保持 4 fps，YOLO 23 个模块、LSTM 10 层、ST-GCN 10 块、池化、logits 与 tracks 继续实时推送。
- **详细帧**：默认 1 fps，独立于层输出节奏。
  - 详细子帧交替：奇数子帧采集 4 个 YOLO 模块 + 1 个 ST-GCN 块的空间/中间时间行；偶数子帧不采 YOLO，采集 1 个 ST-GCN 块的空间/中间/边界行。
  - YOLO：奇数子帧采集 4 个模块的代表卷积（按 `0-3, 4-7, ...` 轮转），**12 个奇数子帧、约 12 秒覆盖 24 个顶层模块**（23 主干/颈部 + Pose26 头）。
  - ST-GCN：每个详细帧采集 1 个块（轮转），**10 个详细帧覆盖 10 个块**；每个块为每个行人分别采集空间 51 项与时间 `C_in × 9` 项；深层块的边界行在偶数子帧按周期轮转，约 20 秒覆盖全部行人的边界示例。
  - 覆盖按处理墙钟推进：1 fps 时约 6 秒 / 10 秒；实际时间随视频吞吐变化，界面显示采集帧号与覆盖进度。
  - 详细帧发布 `detail.coverage` 事件：已覆盖的 YOLO 模块与 ST-GCN 块、采集帧号。
  - 实时详细采集只在生产推理的现有前向上加钩子，**不为动画额外执行一次模型**。
- **客户端缓存**：浏览器保留每个模块/块最近一次详细算式（有界：23 + 10 × 3 人），切换模块时立即显示；新连接或缺口后从空开始，按覆盖进度填充。
- **服务端缓存**：`LiveBuffer` 保存最近一次详细算式映射，随快照返回；重连后可恢复覆盖，不用等待重新轮转。
- **预算**：单事件上限 128 KiB；普通帧总预算 768 KiB；详细帧总预算 768 KiB，其中详细算式 ≤512 KiB（余量留给同帧层输出）。若详细事件放不下，顺延到下一详细帧并在覆盖事件中记录。事件环提升到 1024 事件 / 8 MiB。真实基准后确认或调整，并在文档记录实测值。
- **性能门槛**：真实视频基准中，启用扩展采集的总处理时间相对关闭采集的增加不超过 15%。若超过：
  1. 详细帧降为 0.5 fps；
  2. 每次采集的 YOLO 模块减为 2 个；
  3. 覆盖窗口相应延长；
  4. 界面显示覆盖进度，不隐瞒采集频率。
- **BN**：实时生产推理若已融合 BN，代表卷积的 `fused=true`，只展示融合后的卷积 + 激活；需要未融合 BN 时切到记录重算。界面明确标注。

### 8.6 记录重算

- `frontend-network` 保留源帧重算与 23 层特征采样；新增按需端点：

  `GET /api/jobs/{id}/yolo-conv?frame=<源帧>&module=<0-22>`

  返回该模块代表卷积的完整乘加（未融合 BN），响应上限 2 MiB。端点对同一源帧复用 `FrontendInspector` 的未融合重算结果，按模块缓存；不触发生产追踪器。
- `network` 保留 LSTM 全部五轮、10 块 ST-GCN、池化与分类的完整代表算式。
- 记录重算的完整卷积项数同样受 4096 项上限约束；超限时端点返回明确错误，不截断。
- 记录模式只用于辅助检查，界面始终标明「记录重算」；默认仍以实时数据为主。
- 分析运行中不提供记录模式；完成、失败或取消后可用。
- 记录模式下，步骤 ② 展示源帧重算检测（无 ID）；步骤 ③ 使用保存记录的 tracks 与 ID，不把重算检测强行匹配到 ID。

### 8.7 兼容与回归

- 现有 SSE 事件、快照、tracks、下载格式保持向后兼容；新增字段为增量。
- 关闭扩展采集时，推理输出、JSONL 与标注视频逐值一致。
- 旧任务缺少详细算式时显示「本任务没有详细采集」，不补造。
- 记录重算与视频推理互斥的现有约束保留。

## 13. 实施顺序

每一阶段都以真实数据与测试收口，再进入下一阶段。

1. **数据与后端扩展**：`GET /api/model`、紧凑 `dense_conv`、YOLO 23 模块代表卷积、ST-GCN 10 块轮转、覆盖缓存、预算与回归测试。
2. **蓝图视觉底座 + 长廊骨架**：设计 token、静态六展位、相机系统、骨架/特征/图/意图图层、空态；先用记录数据或回放夹具。
3. **步骤 ①②③**：源帧、检测框、17 关节、ID 绑定、50 帧历史、实时预热。
4. **步骤 ④⑤⑥**：LSTM 五轮、ST-GCN 块切换、池化/Softmax、实时联动。
5. **两处放大镜 + 数值台**：完整卷积/图算式、筛选、倒拖、冻结、客户端缓存。
6. **工作台与结果页重写**：上传、分析、恢复、下载、错误状态。
7. **性能与视觉收口**：1920×1080 实测、开销门槛、降级路径、标签避让、文档与浏览器检查。

## 14. 风险与兜底

| 风险 | 兜底 |
| --- | --- |
| 扩展实时采集拖慢推理 | 15% 门槛；降详细帧频率/每次采集数；保证最终覆盖并如实标注 |
| SSE 载荷过大或浏览器内存增长 | 紧凑数组、轮转、每事件 128 KiB、客户端有界缓存、服务端详细映射有界 |
| 23 模块 + 50 骨架造成视觉噪声 | 只亮当前与相邻展位、最多 3 个标签、数值收进数值台 |
| 细线在投影仪上过细 | 骨架/关键连接使用世界宽度线段；1920×1080 实测后调整线宽与对比度 |
| 实时预热期空屏 | 明确「等待 50 次观测」进度；已到的骨架与 ID 正常展示 |
| 重写破坏现有工作任务 | 保留后端接口与任务语义；端到端回归测试与真实视频检查 |
| WebGL 在教室电脑不可用 | 数值台 + SVG 骨架降级；提供记录视图 |

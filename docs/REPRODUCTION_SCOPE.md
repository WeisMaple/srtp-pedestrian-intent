# 论文复现与代码升级范围

本项目当前目标是复现原论文的车载视频行人意图预测，并升级工程实现。方法主链保持为：历史骨架 → LSTM 预测未来骨架 → ST-GCN 意图分类。

## 保留的方法

- 输入为同一行人的 50 次骨架观测，每次包含 COCO 17 点的 x、y 和置信度。
- LSTM 仍为原 10 层、hidden_size=256，一次预测 10 次姿态，递归 5 次得到未来 50 次姿态。
- ST-GCN 仍使用原人体图和三类输出，原模型代码与原始权重保留。
- 默认使用原恢复代码的固定参考二样本归一化 `legacy_pair`，行为结果逐帧更新 `classify_every=1`。
- 50 次观测不是对固定秒数的严格定义；新旧跟踪的缺帧和历史策略需单独记录。

## 两个对照版本

| 项目 | 原方法基线 | 工程升级版 |
| --- | --- | --- |
| 入口 | `run_legacy_prediction.py` / `reproduction_20261027/` | `run_prediction.py` |
| 检测与姿态 | YOLOv7 + 裁剪 YOLOv8 Pose | YOLO26s-Pose 一次输出行人框与17点 |
| 跟踪 | 原 DeepSORT / TensorFlow ReID | ByteTrack，另可选 BoT-SORT |
| 行为网络 | 原 LSTM + ST-GCN | 相同结构的 PyTorch LSTM + ST-GCN |
| 神经网络推理设备 | 按原代码的 CPU/CUDA 分配 | 默认全部在 CUDA |
| 默认行为更新频率 | 每帧 | 每帧 |

YOLO 与跟踪替换会改变特征分布，因此升级版与原方法基线的结果分别记录。工程升级版保留原预测任务与后端网络结构，不等于逐数值相同的原实现。

## 已完成与结果口径

上轮已用原前端重建 JAAD 数据，并训练 ST-GCN 和 LSTM。ST-GCN 第125轮内部验证准确率为96.38%；该验证有窗口重叠及全数据归一化问题，不能作为独立测试集精度，也不能转移为新版 YOLO 的精度。

升级版已接通新前端并完成视频推理和接口测试。2026-10-28 已完成 YOLO26 骨架全量提取及独立视频划分下的新旧前端重训，代码见 `independent_20261028/`，产物见 `D:\SRTP_independent_20261028`。入口默认权重仍保留上轮版本，本次候选权重另存；运行时可用 `--stgcn` 与 `--lstm` 显式选择。

默认 LSTM 使用上轮 weight_decay=0 对照组的权重；原源代码 weight_decay=1e-4 组保留在复现产物中。论文未指定该参数，报告须说明这项受控比较。

`--task classify`、`--normalization training_stats` 和 `--classify-every 5` 是显式诊断或展示选项。论文主流程默认使用 `predict`、`legacy_pair` 和逐帧更新。

历史600帧21.19 FPS的数据采用每5帧更新行为分类。改回逐帧默认后，应按实际日志报告速度，不能沿用该数字。

本次新版前端重训沿用论文网络和训练主设置，按官方 188/32/126 个视频划分训练/验证/测试，归一化统计只用训练集。共同 598 个测试点：原前端重训 74.75%，新版重训 76.92%；差值的按视频 bootstrap 95% 区间跨零，且多数类基线为 77.59%，不能宣称准确率已显著提高。该实验与旧窗口划分的内部验证分数分别记录。

三段同源视频逐帧运行的吞吐为 4.16→22.05 FPS，但行为预测次数为 261→108；不能把 5.30 倍吞吐比解释为同等行为工作量的纯算法加速。batch=1 相同骨架的行为推理中 CPU 快于 CUDA。详细结果见 `D:\SRTP_independent_20261028\对比报告.md`。

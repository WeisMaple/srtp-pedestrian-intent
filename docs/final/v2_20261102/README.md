# 最终版 v2.0.0 实验结果

最终方案：YOLO26s-Pose → ByteTrack → 50次历史骨架 → 相对表示 LSTM（5轮×10步）→ ST-GCN。保留原网络层数与隐藏维度，采用递归训练、三折预测骨架分类训练及频数平方根倒数类别权重。

| 评价 | 样本数 | 准确率 | Macro-F1 |
|---|---:|---:|---:|
| 验证集 | 368 | 88.86% | 0.6915 |
| 测试集 | 1506 | 82.40% | 0.5368 |
| 历史骨架分类消融对照 | 1506 | 78.02% | 0.4639 |

训练/验证/测试为176/44/126段不同视频。测试覆盖率1506/4189=35.95%。类别采用行人级crossing属性；测试视频此前已用于项目开发，未按过街事件提前量评价。

`matched_ablation.json` 包含相同训练配置下的配对消融及2000次按视频bootstrap区间。`class_weight_protocol.json`、`selection_before_test.json` 记录固定配置与测试前选模。`runtime_parity.json` 证明部署与所选实验模型的概率和未来骨架一致；`runtime_checks.json` 记录150帧GPU检测/CPU行为推理，关闭/开启计算采样为14.72/14.38 FPS，逐帧预测记录相同。

功能验证：110项Python测试、68项前端测试通过；Vite构建通过；实际上传、推理、回放及交互录制无浏览器错误。
